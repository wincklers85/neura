# NÈURA v0.4 — GUI completa

Versione con tema chiaro predefinito e interfaccia sobria, responsive per PC e smartphone.

## Funzioni incluse

- chat privata con modello locale;
- tema chiaro e scuro;
- memoria persistente e feedback;
- dashboard con statistiche e grafico attività;
- diario interno;
- aggiornamento/consolidamento su richiesta;
- storico versioni;
- backup del database;
- Laboratorio che propone codice, patch e test senza applicarli;
- dettatura vocale e lettura delle risposte;
- stato del modello;
- nuova conversazione.

## Deploy Render

Carica il contenuto della cartella nel repository GitHub e crea un Blueprint su
Render. Imposta `APP_PASSWORD`. Il modello locale viene scaricato al primo avvio.

Il Laboratorio genera proposte: il codice va sempre revisionato e applicato
manualmente nel repository prima del nuovo deploy.
